# คู่มือ — อ่านรายงานแต่ละตัว

ทุกรายงานมีโครงเดียวกัน: หัวเรื่อง + 'ช่วงเวลา …' (พ.ศ.) → ปุ่ม **รีเฟรชตอนนี้ / ส่งออก Excel / ส่งออก PDF** → ช่วงเวลา **เดือนนี้ · เดือนที่แล้ว · ไตรมาสนี้ · ปีนี้ · กำหนดเอง** → ตัวเลือกจัดกลุ่ม (ถ้ามี) → การ์ด KPI → กราฟ → ตาราง + แถว 'รวมทั้งหมด' → หมายเหตุ → 'ข้อมูล ณ DD/MM/2569 HH:mm (คำนวณสด/จากแคช)'
- กด 'รีเฟรชตอนนี้' ซ้ำภายใน 5 นาที → กล่อง 'เพิ่งรีเฟรชไปเมื่อครู่' (ข้อมูลเป็นชุดที่คำนวณไว้)
- **ปุ่มส่งออกใช้ชุดข้อมูลที่แคชไว้** → กดรีเฟรชก่อนส่งออกเสมอ
- ช่วงวันที่ผิด (เริ่มหลังสิ้นสุด) → ข้อความใต้ช่องวันที่ 'ช่วงวันที่ไม่ถูกต้อง'
