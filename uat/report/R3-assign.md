## วิธีอ่านเรื่อง "ขอเปลี่ยนผู้รับผิดชอบ → ไม่มีใครตอบ → ระบบโอนเอง"

1. **มอบหมาย**: ผู้จัดการ/หัวหน้าเลือกพนักงานให้เคส → เคสเป็น "มอบหมายแล้ว (รอรับ)"
2. **พนักงานกดรับงาน** → "รับงานแล้ว" (จากจุดนี้ เปลี่ยนคนทันทีไม่ได้แล้ว เพราะพนักงานอาจวางแผนออกพื้นที่ไว้)
3. **ผู้จัดการกด "เปลี่ยนผู้รับผิดชอบ"** เลือกคนใหม่ + เหตุผล → ระบบ**ยังไม่เปลี่ยน** แต่สร้าง "คำขอ" ส่งไปถามพนักงานคนเดิม พร้อม**เส้นตาย** = เวลาที่ขอ + "เวลารอความยินยอม" ในหน้าตั้งค่า (ค่าเริ่มต้น 3 ชม. — รอบนี้ลดเหลือ 1 ชม.) · ค่าเส้นตายถูก**จดตายตัวตอนส่งคำขอ** แก้ตั้งค่าทีหลังไม่ย้อนไปกระทบ
4. ระหว่างรอ: หน้ามอบหมายแสดงป้าย "รอความยินยอมเปลี่ยนผู้รับผิดชอบ" + "เหลืออีก NN นาที" · ปุ่มเปลี่ยนผู้รับผิดชอบหายไป (ขอซ้ำไม่ได้) · พนักงานคนเดิมเห็นแถบ "มีคำขอเปลี่ยนผู้รับผิดชอบ" ในแอป กด "ตอบเลย" เพื่อยินยอม/ไม่ยินยอม
5. **ถ้าไม่มีใครตอบจนเลยเส้นตาย**: งานเบื้องหลัง `reassign_timeout` (ปกติรันตามรอบ cron — รอบนี้ Superadmin สั่งเองผ่าน `POST /api/dev/trigger-job`) จะ "โอนให้อัตโนมัติ": แถวของคนเดิมเป็น `reassigned_away`, สร้างแถวใหม่ให้คนใหม่สถานะ "มอบหมายแล้ว (รอรับ)", คำขอเป็น `timeout_auto`, ลงประวัติ + audit (ผู้กระทำ = ระบบ อ้าง job id) และแจ้งเตือนคนเดิม/คนใหม่/ผู้ขอ
6. คนเดิมกดตอบหลังหมดเวลา → ระบบปัด `REASSIGNMENT_ALREADY_TIMED_OUT`
