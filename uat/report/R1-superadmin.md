## ❓ ต้องตัดสินใจ
- **Q-A [R1.41]** ธุรการ (`uat.admin`) ถือ `manage_users = manage` และเรียก `/api/users` ได้ แต่หน้า/เมนู "ผู้ใช้งาน" ถูกจำกัดให้ Superadmin/บริหาร (`05` §12 vs `06` §7.2 ขัดกัน — โค้ดเลือก `06`) ⇒ ธุรการจัดการผู้ใช้ผ่านหน้าจอไม่ได้ · ตัวเลือก: ก (แนะนำ) เปิดแท็บ "ผู้ใช้งาน" ให้ธุรการ (scope เฉพาะกลุ่มที่ไม่ใช่ system ตาม DEC-010) + แก้ `06` ให้ตรง `05` · ข คงตาม `06` แล้วถอด `manage_users` ออกจากธุรการใน seed/`07` ให้สิทธิ์ API ตรงกับหน้าจอ · ค คงไว้แบบนี้ (สิทธิ์ API กว้างกว่าหน้าจอ)
- **Q-B [R1.43] (= Q5 เดิม)** ผู้ใช้บริษัทไฟแนนซ์เข้า App Shell ภายในได้ (`/dashboard`, `/cases`, `/warehouse`) และ `/api/assets`, `/api/handover-lots`, `/api/cases` ตอบ 200 · ตัวเลือก: ก (แนะนำ) redirect ผู้ใช้กลุ่ม finance_company ทุกเส้นทางภายในไป `/portal` จนกว่า Portal (7.3) จะเสร็จ + ให้ R2/R5 ตรวจว่า API กรองเฉพาะ company_id ตัวเอง · ข ยอมรับไว้ก่อน (แสดงหน้าโครง) แต่บังคับตรวจ scope ใน R2/R5 เป็น probe S3
