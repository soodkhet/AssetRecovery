### 0.3 State machine / ป้าย 📄
- **bank_transactions.match_status** (`lib/bank-recon/matching.ts`): `unmatched` → `auto_matched` (ตอนนำเข้า) | `manual_matched` (เจ้าหน้าที่ — จาก unmatched/auto/manual ได้) | `unmatched_resolved` (จาก unmatched เท่านั้น · **terminal**) · ป้าย 'ยังไม่จับคู่' / 'จับคู่อัตโนมัติ' / 'จับคู่โดยเจ้าหน้าที่' / 'ปิดรายการแล้ว'

- จับคู่บิล → `cash_receipts` 1 แถว (`wht_withheld_by_customer_satang` = ส่วนต่างเมื่อยอดตรง alt) → `applyBillingReceipt()` → `paid` ถ้า received + wht ≥ total
- จับคู่รอบจ่าย → `syncPayoutBatchCompleted()` → `completed` (audit `confirm` `after.confirmed_source='bank_reconciliation'`, reason 'จับคู่กับรายการเดินบัญชี <id> สำเร็จ') + แจ้งเตือน `payout_batch.completed` → `syncExpenseRecordsFromPayout()` → `syncWhtCertificatesFromPayout()` (1 ใบต่อ expense_record ที่ WHT > 0)
- **advance**: `approved` → job `advance_overdue` → `overdue` (due_clear_date < วันที่ไทยของ now/asOf) · `approved|overdue` → settle → `cleared`
- **wht_certificate**: `active` → ยกเลิก (เหตุผล) → `cancelled` (+ ออกแทน `replaces_certificate_id`) · **accounting_period**: `collecting` → send (ผ่าน Readiness) → `sent_to_accountant` → lock (R8) · **exception**: `open` → `resolved` | `authorized` (บริหาร — R8) · **export_record**: `generated` → `sent` → `accepted`
