### 0.4 ตัวช่วยและแบบแผนที่ใช้ทุก step

```js
import { openAs, shot, BASE } from './lib.mjs'          // รันจากรากโปรเจกต์ (path ใน lib เป็น relative)
const { browser, context, page, consoleErrors, serverErrors } = await openAs('admin')
// toast: page.getByRole('status')  ·  modal: page.getByRole('dialog')  ·  inline error ใต้ช่อง: dlg.locator('.text-red-600')
// ทุกฟอร์มสำคัญปิดด้วย "ยกเลิก" (ปุ่มรอง) / บันทึกด้วยปุ่มหลักที่ระบุใน step
```

- **ล็อกอินครั้งแรกด้วย `initial` ห้ามใช้ `openAs()`** (มันใช้ฟิลด์ `password` + เก็บ storageState) → ใช้สคริปต์ใน R1.39
- เงินในฟอร์มกรอกเป็น **บาท** (เช่น `2,140.00`) — DB เก็บ satang (`214000`) · `<input type="date">` กรอก ISO ค.ศ. (`2026-10-01`) แต่บนจอต้องแสดง พ.ศ.
- ตรวจหลังบ้าน: `uat/bin/q.sh "<sql>"` (read-only) · audit = ตาราง `audit_logs` คอลัมน์ `actor_id, actor_role, action, target_type, target_id, before_data, after_data, reason, created_at` (enum action: create/update/delete/status_change/approve/reject/confirm/lock/unlock/export/import/login/logout)
- SQL audit มาตรฐาน (แทน `<T>` ด้วย target_type):
  `uat/bin/q.sh "select action, actor_role, reason, created_at from audit_logs where target_type='<T>' order by created_at desc limit 5"`
- ทุก step: ภาพ "ก่อนกดบันทึก" (`R1.NN-<slug>-form`) + "หลังผลลัพธ์" (`R1.NN-<slug>-done`) ด้วย `shot(page,'R1',...)` · จด `consoleErrors`/`serverErrors` ถ้าไม่ว่าง · ท้ายรอบดู `pm2 logs asset-web --nostream --lines 100`
- เมนูตั้งค่า = เมนูบน "การตั้งค่า" → แถบย่อย: สิทธิ์การใช้งาน · ผู้ใช้งาน · แผนค่าตอบแทน · เทมเพลตค่าบริการ · ทีมติดตามทรัพย์ · บริษัทไฟแนนซ์ · ตั้งค่าบัญชี/การเงิน · บันทึกการใช้งาน (Audit Log) · งานเบื้องหลัง (Job Log)
- หน้า "ตั้งค่าบัญชี/การเงิน" แท็บเป็น **ปุ่ม** (ไม่ใช่ role=tab) — เข้าตรงด้วย `?tab=` ได้: `cycles, approval, bank, payee, tax, vat, cost, docs, bankfile, export, permission, lock, numbering, taxdoc, sla`
