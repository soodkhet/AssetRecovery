### 0.3 State machine ที่ใช้
**assignment** (`41` §10 · enum `assignment_status` `02` §3 — `23` ไม่มี state ของ assignment):
```
pending_accept ─รับงาน (POST /api/field/cases/:id/accept)─► accepted_unscheduled ─จัดวันที่ (POST …/schedule {scheduleDate})─► scheduled  (case.status approved → active)
scheduled ─เช็คอิน ≥1 + หลักฐานครบ → ยืนยันปิดงาน (POST …/close)─► closed_success | closed_fail   (case.status = closed_success | closed_fail)
closed_* ─reject_evidence (เจ้าหน้าที่อนุมัติเคส: POST /api/cases/:id/reject-evidence {reason≥5})─► needs_revision
needs_revision ─แก้สื่ออย่างน้อย 1 รายการ → ส่งกลับยืนยันอีกครั้ง (POST /api/field/cases/:id/resubmit-close)─► closed_* เดิม (outcome + เช็คอินล็อก)
```
- เช็คอินทำได้เฉพาะ `scheduled` · `reject_evidence` ถูกบล็อก `EVIDENCE_REJECT_AFTER_FINAL` ถ้ามี asset `handed_over` / มี revenue / expense เข้ารอบจ่ายแล้ว (R4 ยังไม่มีทั้งหมด ⇒ ตีกลับได้)

**expense** (`23` §6.3 · enum `expense_status`: `pending_warehouse_confirm, pending_approval, pending_finance_approval, approved, rejected, needs_revision, superseded`):
- ปิด**สำเร็จ** → fuel/allowance `pending_warehouse_confirm` (รอยืนยันล็อต R5) · ปิด**ไม่สำเร็จ** → `pending_approval` ทันที (ไม่ผ่านคลัง)
- resubmit_close → แถวเดิมที่ยัง active และไม่อยู่ในรอบจ่าย → `superseded` + `superseded_by_expense_id` · สร้างชุดใหม่ตามกฎปกติ
- ยอด: แผนของ**ทีมพนักงาน** ณ วันปิดงาน (`comp_plan_id` + `comp_plan_version` snapshot) · fuel DAILY_FLAT = ค่าคงที่ต่อเคส · allowance = อัตรา × วันเช็คอินไม่ซ้ำ (เวลาไทย) · ยอด 0 = ไม่สร้างแถว · **ไม่มีการสร้าง commission / no_success_fee เลย** (BUG-010)
- กันซ้ำ: `updateMany … where status='scheduled'` (คำขอที่ 2 = 400 `ASSIGNMENT_INVALID_STATUS`) + partial unique index `uniq_active_case_expense_per_assignment(assignment_id, expense_type) WHERE status <> 'superseded'`

**advance** (`15` §9 · `advance_status`): `pending_approval → approved | rejected` · `approved → overdue` (job) · `approved|overdue → cleared` · ใบซ้อนถูกบล็อกเมื่อมีใบ `approved|overdue` (partial unique `uniq_active_advance_per_payee` + เช็คตอนสร้าง **และ**ตอนอนุมัติ) — **`pending_approval` ไม่บล็อก**
