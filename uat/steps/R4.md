### 0.3 State machine ที่ใช้
**assignment** (`41` §10 · enum `assignment_status` `02` §3):
```
pending_accept ─รับงาน─► accepted_unscheduled ─จัดวันที่─► scheduled (case approved → active)
scheduled ─เช็คอิน ≥1 + หลักฐานครบ (+เหตุผลถ้าไม่สำเร็จ) → ยืนยันปิดงาน─► closed_success | closed_fail
closed_* ─reject_evidence (เจ้าหน้าที่อนุมัติเคส — หน้าจอ /cases/submit)─► needs_revision
needs_revision ─แก้สื่อ ≥1 → ส่งกลับยืนยันอีกครั้ง─► closed_* เดิม (outcome + เช็คอิน + เหตุผลไม่สำเร็จ ล็อก)
```
- `reject_evidence` ถูกบล็อก `EVIDENCE_REJECT_AFTER_FINAL` เมื่อหลักฐานผ่านแล้ว (Q14: คลังรับเข้า/ค่าตอบแทนอนุมัติ) / asset handed_over / มี revenue / expense เข้ารอบจ่าย — R4 ยังไม่มี ⇒ ตีกลับได้

**expense** (`23` §6.3): ปิด**สำเร็จ** → fuel/allowance/**commission** `pending_warehouse_confirm` · ปิด**ไม่สำเร็จ** → fuel/allowance/**no_success_fee** `pending_approval` ทันที · resubmit → แถวเดิม `superseded` + `superseded_by_expense_id` = แถวใหม่**ชนิดเดียวกัน** (BUG-051) · ชุดใหม่ราคา/plan/`expense_date` = ปิดครั้งแรก (Q7) · hotel → `pending_approval` · กันซ้ำ `uniq_active_case_expense_per_assignment(assignment_id, expense_type) WHERE status <> 'superseded'`

**case_evidences** (Q14): `pending` ตลอด R4 · แถวที่ถูกตีกลับ → `rejected` · ผ่านอัตโนมัติใน R5/R6 เท่านั้น

**advance** (`15` §9): `pending_approval → approved | rejected` · `approved → overdue` (job) · `approved|overdue → cleared` · ใบซ้อนบล็อกเมื่อมี `approved|overdue` — **`pending_approval` ไม่บล็อก**

### 0.4 Error code ที่คาด (400 เว้นระบุ)
`CLOSE_OUTCOME_REQUIRED` `CLOSE_CHECKIN_REQUIRED` `CLOSE_PHOTO_REQUIRED` `CLOSE_VIDEO_REQUIRED` `CLOSE_PRODUCT_PHOTO_REQUIRED` **`CLOSE_FAIL_REASON_REQUIRED`** (body `missing:[…]` ครบ) · `CLOSE_NO_EVIDENCE_REVISION` · `CHECKIN_GPS_PERMISSION_DENIED` · `ASSIGNMENT_INVALID_STATUS` · `ASSIGNMENT_NOT_FOUND` (404) · `EVIDENCE_REJECT_AFTER_FINAL` · **`UPLOAD_PATH_OUT_OF_SCOPE` `UPLOAD_FILE_TYPE_INVALID`** (+`UPLOAD_FILE_NOT_FOUND`/`UPLOAD_FILE_TOO_LARGE`/`UPLOAD_HASH_MISMATCH`) · Zod = `REQUIRED_MISSING` + `fields` · `PERMISSION_DENIED` (403) · เงินทดรอง: `ADVANCE_EXCEEDS_MAX` · `ADVANCE_PENDING_SETTLEMENT` · `ADVANCE_INVALID_STATUS` · วันเคลียร์ย้อนหลัง = `REQUIRED_MISSING` fields.dueClearDate (Q8 ไม่ตั้ง code ใหม่)
