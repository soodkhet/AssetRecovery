### 0.2 ลายนิ้วมือ + เวลา
- `T0` = เวลาเริ่ม (UTC) · `uat/bin/counts.sh` ก่อน/หลัง · audit action ที่มีจริงในระบบ (ไม่มี `intake`/`cancel`/`match`/`suspense`/`refund` — ใช้ชื่อด้านล่าง):
  | การกระทำ | action |
  |---|---|
  | รับเข้าคลัง · ยกเลิกรอบจ่าย (+reason) · ย้ายเงินรอตรวจสอบ/คืนเงินผู้โอน · บันทึกรับ 50 ทวิ ลูกค้า · ส่งงวด | `status_change` |
  | สร้างไฟล์โอนธนาคาร · ดาวน์โหลดใบส่งมอบ/ใบกำกับ/Export Pack | `export` |
  | ยืนยันโอนรอบจ่าย | `confirm` |
  | นำเข้า statement | `import` |
  | แก้บริษัท (สาขา) · จับคู่ธนาคาร | `update` |
  | ตีกลับรายการเบิก | `reject` |
  | ล็อกงวด | `lock` |
  | สร้างข้อมูลใหม่ (ค่าตั้งภาษี, เงินทดรอง, รับคืน ฯลฯ) | `create` |

- action ที่เห็นแต่ไม่อยู่ในตาราง → บันทึกค่าที่เห็น (ไม่ใช่บั๊กอัตโนมัติ)
