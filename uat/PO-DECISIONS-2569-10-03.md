## ข้อสังเกตหลังแก้ตามมติ (ไม่บล็อก — ถามรวดรอบหน้า)
- Q1: `44` §13 ระบุให้ผู้จัดการทีมรับเข้าคลัง/ตีกลับได้ด้วย แต่ตอนนี้ผูกสิทธิ์ให้ธุรการคนเดียวตามมติ — จะให้ผู้จัดการทีมทำได้ด้วยไหม (ต้องตรวจ scope ทีมใน `assetScopeWhere` ก่อน)
- Q11: `38` §13 แถว `edit_case` ยังให้ Manager แก้เคสสถานะ pending แต่ตอนนี้ Manager มองไม่เห็นเคสเหล่านั้นแล้ว — ตัด Manager ออกจากแถวนั้นไหม
- Q7 (+R4b v2): หลังส่งหลักฐานใหม่ list แสดง "ปิดงานเมื่อ" = เวลาส่งใหม่ (`completed_at`) — ควรแสดงเวลาปิดครั้งแรกหรือเวลาส่งใหม่ · ตอน resubmit ราคา expense ยึดวันปิดงานครั้งแรก แต่ `cases.closed_at` (ซึ่งเป็นวันที่ของรายได้) ยังเป็นเวลาที่ resubmit — ถ้าข้ามเดือนรายได้จะไปลงงวดใหม่ ควรยึดวันไหน
- BUG-072: เพดานค่าที่พักต่อคืน (`hotel_max_per_night`) — `11`/`22`/`41` ไม่ระบุว่าเกินให้บล็อกหรือจ่ายแค่เพดานแล้วเตือน และฟอร์มไม่มีช่องจำนวนคืน (ใบเสร็จ 1 ใบครอบหลายคืนได้) ⇒ เพิ่มช่องจำนวนคืนไหม + เกินเพดานทำอย่างไร
- BUG-062: แผนที่ย่อตอนเช็คอิน — ตอนนี้แสดงพิกัด + ลิงก์ Google Maps แทนรูปแผนที่ (โดเมนเดิมตาย) · ถ้าต้องการภาพแผนที่จริงต้องเลือกผู้ให้บริการ (อาจต้องมี API key)
