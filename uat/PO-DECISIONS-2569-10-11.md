## มติ PO 12/10/2569 — I2-01 (mytester รอบ 2) · แทนนิยาม "ยอดจริง" ของ M9
- **เรื่อง**: พอร์ทัลบริษัทไฟแนนซ์ › รายละเอียดเคส › "ค่าบริการ (ยอดจริง)" ไม่สะท้อนใบลดหนี้ (NDP-04 ยอด ฿200 ลดหนี้ CN-NDP-2569-0012 เต็ม ฿200 แต่ยังแสดง ฿200)
- **มติ**:
  1. ยอดจริง = ยอดรายได้ของเคส − ใบลดหนี้ที่**ออกแล้ว (active ไม่ยกเลิก)** ที่ผูกกับรายได้ของเคสผ่าน Adjustment ⇒ NDP-04 แสดง ฿0.00
  2. มีใบลดหนี้ ⇒ บรรทัดย่อยใต้ตัวเลข "ยอดเดิม ฿200.00 · ลดหนี้ CN-NDP-2569-0012 −฿200.00" (หลายใบแสดงทุกเลข) · ไม่มีใบลดหนี้ = ไม่มีบรรทัดย่อย
  3. Adjustment ลดยอดที่อนุมัติแล้วแต่ยังไม่ออกใบลดหนี้ = ยังไม่หัก/ไม่แสดงในพอร์ทัล (ยอดตรงเอกสารภาษีที่ลูกค้าได้รับจริง)
  4. ใบลดหนี้ที่ยกเลิกไม่นับ · ฐาน VAT เดียวกับตัวเลขเดิม: ยอดรายได้**รวม VAT** − ยอดรวม VAT ของใบลดหนี้ · ไม่ต่ำกว่า 0
  5. เคสไม่สำเร็จที่ "ไม่เรียกเก็บ" คงเดิม
- **ขอบเขตที่ implement**: นับเฉพาะใบลดหนี้ (`credit`) ที่ผูก Adjustment ซึ่งชี้รายได้ของเคสโดยตรง — ใบลดหนี้ระดับใบกำกับที่ไม่ผูกรายได้ของเคส และใบเพิ่มหนี้ ไม่นำมาคิดในช่องนี้
- **อัปเดตสเปค**: `docs/97` v6.11 (§6.6)

## มติ 12/10/2569 — G3-01 (mytester รอบ 3) · ใบเสร็จรับเงิน/ใบกำกับภาษีหลังใบลดหนี้ (ตัดสินแทนนักบัญชี ตามหลัก ม.78/1(2) — ความรับผิด VAT ค่าบริการเกิดเมื่อได้รับชำระ) · **ผู้ใช้ยืนยัน 09/11/2569**
- **เรื่อง**: BL-2569-002 (NDP · รวม VAT) ใบแจ้งหนี้ 3,072.55 · รับ 2,000 ⇒ IV-2569-0001 (1,869.16 + 130.84) · CN-NDP-2569-0012 ฿200 อ้าง IV-0001 · รับครั้งที่ 2 ครบ 872.55 (786.40 + ลูกค้าหัก 86.15) ⇒ ระบบออก IV-2569-0003 ฿872.55 "รับชำระบางส่วนครั้งที่ 2" พิมพ์ยอดคงค้าง 200.00 ทั้งที่ AR = 0 ⇒ ใบกำกับสุทธิของรอบ 2,672.55 < มูลค่าสุทธิหลังลดหนี้ 2,872.55 (มูลค่า 186.92 + VAT 13.08 ไม่มีใบกำกับ)
- **มติ**:
  1. ยอดใบเสร็จฯ ที่ออกเมื่อรับชำระ = เงินที่รับครั้งนี้ (รวมภาษีที่ลูกค้าหัก) **+ เครดิตจากใบลดหนี้ที่ยังไม่ถูกนำไปออกใบ** (ใบลดหนี้ที่ลดใบเสร็จฯ ซึ่งลูกค้าชำระเต็มแล้ว = เงินที่ชำระไว้แล้วถูกนำมาชำระยอดคงเหลือ) ไม่เกินมูลค่าที่ยังไม่ออกใบของรอบ · หลักการตรวจ: รอบรับชำระครบ ⇒ Σ ใบกำกับ − Σ ใบลดหนี้ + Σ ใบเพิ่มหนี้ = ยอดสุทธิของรอบทุกสตางค์
  2. ใบเพิ่มหนี้เป็นเอกสารภาษีในตัว (ม.86/9) ⇒ เงินที่ชำระส่วนเพิ่มหนี้ไม่ออกใบเสร็จฯ ซ้ำ (ใบปิดยอดออกเท่ายอดคงเหลือ · ส่วนที่เกิน = ไม่ออกเอกสาร)
  3. ข้อความ "ครั้งที่ n / ยอดคงค้าง" คิดจากยอดค้างจริงหลังใบลดหนี้/ใบเพิ่มหนี้ (ณ เวลาออกใบ) · รอบครบ ⇒ "รับชำระครั้งที่ n (ครบยอด)" ไม่พิมพ์ยอดคงค้าง · PDF แถว "หัก ยอดชำระไว้แล้วตามใบลดหนี้ (นำมาชำระยอดคงเหลือ)"
  4. สูตร VAT/ปัดเศษเดิม (ใบปิดยอด VAT = VAT ใบแจ้งหนี้ − VAT ที่ออกแล้ว · รับบางส่วน VAT = ยอด × อัตรา/(100+อัตรา)) · ใบที่ออกแล้วไม่แก้
- **ผลกับตัวอย่าง**: ใบปิดยอดของ BL-2569-002 = 1,002.38 + VAT 70.17 = **1,072.55** ⇒ 2,000 + 1,072.55 − 200 = 2,872.55 = เงินที่รับ + ภาษีลูกค้าหัก
- **วิธีแก้ข้อมูลเดิมบน staging (IV-2569-0003 — ผู้ใช้ทำเองหลัง deploy โค้ดนี้)**: ที่แนะนำ = **ยกเลิก IV-2569-0003** (เหตุผล "ยอดไม่รวมเครดิตจากใบลดหนี้ CN-NDP-2569-0012 — ออกใบแทน") แล้วกด **ออกแทน** ⇒ ระบบคิดใหม่จากเงินรับเดิมได้ใบเลขใหม่ 1,002.38 + 70.17 = 1,072.55 "รับชำระครั้งที่ 2 (ครบยอด)" พร้อมข้อความ "ออกแทนฉบับเลขที่ IV-2569-0003 …" (วันที่เอกสารต้องไม่ก่อนใบเลขก่อนหน้า — เลือกวันนี้ถ้าระบบเตือน · งวดต้องยังไม่ปิด) · ถ้าส่งต้นฉบับ IV-0003 ให้ลูกค้าแล้วให้เรียกคืน/แจ้งยกเลิกตามปกติ · ถ้างวดภาษีของ IV-0003 ยื่น ภ.พ.30 ไปแล้ว ให้สำนักงานบัญชียื่นเพิ่มเติมส่วนต่าง VAT 13.08 นอกระบบ · **ไม่แนะนำ**ใช้ใบเพิ่มหนี้ 200 อ้าง IV-0001 แทน (ผลรวมเงินตรงแต่ผิดข้อเท็จจริง — มูลค่าบริการไม่ได้เพิ่ม และต้องมี Adjustment เพิ่มยอดที่ไม่มีจริง)
- **อัปเดตสเปค**: `docs/22` v3.27 (§6.8.2) · `docs/31` v4.6 (§6.2.1)

## มติ 12/10/2569 — LR3-03 (ทดสอบซ้ำ local mytester รอบ 3) · ยอดจริงของเคสในพอร์ทัลหักส่วนที่ลดแบบไม่ต้องออกใบลดหนี้ (Claude ตัดสินแทน PO — รอยืนยัน) · **ผู้ใช้ยืนยัน 09/11/2569**
- **เรื่อง**: Adjustment ลด FT-06 ฿1,000 ก่อน VAT ในส่วนที่ยังไม่ออกใบ (ปิดอัตโนมัติ "ไม่ต้องออกใบลดหนี้" ตามมติรีวิว R3 #1) ⇒ พอร์ทัลยังแสดง "ค่าบริการ (ยอดจริง)" ฿7,490 ขณะรอบ BL-2569-009 = ฿13,910 (ผลรวมเคส 14,980 ≠ เอกสารภาษี) · มติ I2-01 ข้อ 3 "ยังไม่หักจนมีใบลดหนี้" เขียนก่อนมติรีวิว #1 — กรณีนี้จะไม่มีใบลดหนี้ตลอดไป
- **มติ** (ต่อหลัก I2-01 "ยอดในพอร์ทัลตรงกับเอกสารที่ลูกค้าได้รับจริง"):
  1. ส่วนที่ลดแบบ "ไม่ต้องออกใบลดหนี้" **หักใน "ค่าบริการ (ยอดจริง)" ของเคส** = ยอดก่อน VAT + VAT ตามอัตราของรายได้เคส (รายได้ไม่มี VAT ⇒ ไม่บวก) ⇒ FT-06 ฿7,490 − ฿1,070 = ฿6,420
  2. บรรทัดย่อย "ยอดเดิม ฿7,490.00 · ปรับลด −฿1,070.00" (ไม่มีเลขเอกสาร) · มีใบลดหนี้ด้วย ⇒ ต่อท้าย "ลดหนี้ <เลขที่> −฿y" ตามเดิม
  3. นับ = Adjustment ลดยอด `approved` ของรายได้เคส ที่ยังไม่มีใบลดหนี้ active และ (ปิดอัตโนมัติด้วยเหตุผล "ส่วนที่ลดยังไม่ได้ออกใบกำกับภาษี — ไม่ต้องออกใบลดหนี้" **หรือ** ยังไม่ปิดป้ายแต่รอบไม่เหลือส่วนที่ต้องออกใบลดหนี้ — เกณฑ์เดียวกับป้าย "รอใบลดหนี้" ⇒ ข้อมูลก่อนมติก็ได้ผล)
