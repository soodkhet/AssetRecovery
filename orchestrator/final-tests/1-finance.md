# ด่าน 1/4 — การเงิน + Order flow (E2E)

ทดสอบ flow ธุรกิจข้ามเฟสตั้งแต่ต้นจนจบ ด้วย integration test จริง (PGlite/DB) ไม่ใช่แค่อ่านโค้ด:

1. **Happy path เต็มสาย:** รับป้ายเข้าระบบ → ประกาศขาย → สร้าง Order (reservation + sale) → lock ป้ายกันขายซ้ำ → รับเงินงวดแรก + RC → รับเงินเพิ่มหลายงวด → เอกสารครบ → โอนสิทธิ → จ่ายพาร์ทเนอร์ (PV/PR) → ปิดยอด → เห็นในรายงาน/บัญชี
2. **เคสคืนเงิน/ยกเลิก:** RF + recovery + void flow — ยืนยันว่า**ไม่มี negative mutation** (ต้อง void + สร้างใหม่ + audit เชื่อมโยง)
3. **ความถูกต้องตัวเลข:** เงิน BIGINT สตางค์ทุกจุด · % = basis points · ไม่มี float · snapshot commission ณ สร้าง Order ไม่เปลี่ยนเมื่อแก้ master ทีหลัง
4. **Trace chain ครบ:** ป้าย → Order → รับ/คืนเงิน → จ่าย/รับคืนพาร์ทเนอร์ → เอกสารทุกใบ (16 §34) ตามรอยได้ไม่ขาด
5. **กระทบยอด:** ยอดใน dashboard/รายงาน/หน้าบัญชี = ผลรวมธุรกรรมจริง ตรงทุกบาท

รายงานตาราง `| หัวข้อ | สถานะ | หลักฐาน (ไฟล์/เทสต์) |` แล้วแก้จุดที่ ❌ พร้อม test ที่พิสูจน์
