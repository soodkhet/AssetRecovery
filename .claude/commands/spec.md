---
description: ค้นหาข้อมูลใน spec แบบประหยัด context (ผ่าน INDEX + MAP)
---

หาคำตอบเรื่อง "$ARGUMENTS" จาก spec ของโปรเจกต์ โดย:

1. ดู `docs/00_INDEX.md` เพื่อระบุไฟล์ที่เกี่ยว (ใช้ตารางเส้นทางใน `CLAUDE.md` ประกอบ)
2. ไฟล์ใหญ่ → เปิด `docs/00_MAP.md` หาช่วงบรรทัดของ section ที่เกี่ยว แล้ว `Read(offset, limit)` เฉพาะช่วง
3. ไฟล์เล็ก → Grep คีย์เวิร์ดก่อน แล้วอ่านเฉพาะบริเวณที่เจอ
4. ตอบพร้อมอ้างอิง `<ไฟล์> §<section>` ทุกประเด็น — ถ้าเอกสารขัดกันให้รายงานทั้งสองแหล่งพร้อมลำดับความสำคัญ (schema `02` ชนะ)

ห้ามอ่านไฟล์ใหญ่ทั้งไฟล์เด็ดขาด
