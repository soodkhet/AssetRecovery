## 1. ผู้ดูแลระบบ

**ใคร:** Superadmin (ทุกอย่าง) · บริหาร (บางแท็บ) · ธุรการ (แท็บผู้ใช้งาน / ปฏิทินวันหยุด / Model Phone)
**เมื่อไร:** ตั้งต้นก่อนเปิดใช้ระบบ แล้วทบทวนเมื่อมีทีม/บริษัท/อัตราใหม่

```mermaid
flowchart TD
  %% กลุ่ม 1 — ผู้ดูแลระบบ · เมนู การตั้งค่า (lib/nav/menu-registry.ts)
  s(["เริ่ม: ตั้งค่าระบบ"]) --> o["📍 การตั้งค่า → ข้อมูลองค์กร<br/>ชื่อ · เลขผู้เสียภาษี · บัญชีธนาคาร"]
  o --> fin["📍 การตั้งค่า → ตั้งค่าบัญชี/การเงิน<br/>อัตรา VAT ตามวันที่มีผล · โปรไฟล์ภาษี · สายอนุมัติ<br/>เลขที่เอกสาร · รูปแบบไฟล์ธนาคาร · นโยบายล็อกงวด"]
  fin --> fc["📍 การตั้งค่า → บริษัทไฟแนนซ์<br/>ข้อมูลบริษัท · รอบวางบิล · เงื่อนไขชำระ"]
  fc --> fee["📍 การตั้งค่า → เทมเพลตค่าบริการ<br/>รูปแบบค่าบริการ · ยอดกรณีไม่สำเร็จ"]
  fee --> plan["📍 การตั้งค่า → แผนค่าตอบแทน<br/>ค่าคอมฯ · ค่าน้ำมัน · เบี้ยเลี้ยง"]
  plan --> team["📍 การตั้งค่า → ทีมติดตามทรัพย์<br/>ทีม · จังหวัดที่ดูแล · ผู้จัดการ/หัวหน้า"]
```

## 2. ธุรการ + เจ้าหน้าที่อนุมัติเคส

**ใคร:** ธุรการ (คีย์เคส) · เจ้าหน้าที่อนุมัติเคส (พิจารณา/ตีกลับหลักฐาน/รีไซเคิล)
**เมื่อไร:** ทุกวัน เมื่อบริษัทไฟแนนซ์ส่งเคสมา · 📍 **จัดการเคส → รับเคส**

```mermaid
flowchart TD
  %% กลุ่ม 2 — ธุรการ + เจ้าหน้าที่อนุมัติเคส (lib/cases/state-machine.ts)
  cin(["บริษัทไฟแนนซ์ส่งเคส"]) --> ch{"ธุรการ: กี่เคส?"}
  ch -->|"ทีละเคส"| k1["กรอกเคสใหม่<br/>ลูกหนี้ · ทรัพย์ · IMEI · สัญญา"]
  ch -->|"หลายเคส"| k2["นำเข้าไฟล์"]
  k1 --> dr["สถานะ: ร่าง"]
  k2 --> dr
  dr --> att["แนบเอกสารที่บังคับ"]
  att --> ok{"ข้อมูล + เอกสารครบ?"}
  ok -->|"ไม่ครบ"| att
  ok -->|"ครบ"| sv["กด ส่งตรวจสอบเคส → รอพิจารณา"]
  sv --> ap{"เจ้าหน้าที่อนุมัติเคส<br/>พิจารณา"}
  ap -->|"ขอข้อมูลเพิ่ม + เหตุผล"| ni["ขอข้อมูลเพิ่ม"]
  ni -->|"ธุรการ: กลับไปแก้ไขเป็นร่าง"| dr
  ap -->|"ไม่รับเคส + เหตุผล"| rj(["ไม่รับเคส — จบ"])
  ap -->|"ตรวจทีมที่ระบบเสนอ"| tm{"ทีมตามจังหวัดถูกต้อง?"}
  tm -->|"เปลี่ยนทีม"| tm2["เลือกทีมใหม่"]
  tm -->|"ถูกต้อง"| acc["กด รับเคส & ยืนยันทีม<br/>→ รับเคสแล้ว"]
  tm2 --> acc
  acc --> w1["⏳ รอทีมติดตามมอบหมาย + ลงพื้นที่<br/>(กลุ่ม 3)"]
  w1 --> cl{"พนักงานปิดงานแล้ว<br/>ตรวจหลักฐาน"}
  cl -->|"หลักฐานไม่ครบ/ไม่ถูก"| rev["กด ตีกลับหลักฐาน + เหตุผล"]
  rev --> w1
  cl -->|"ปิดงานไม่สำเร็จ ควรติดตามใหม่"| rc["ขอรีไซเคิล → รออนุมัติรีไซเคิล"]
  rc --> rd{"อนุมัติรีไซเคิล?"}
  rd -->|"อนุมัติ (รอบติดตาม +1)"| w1
  rd -->|"ไม่อนุมัติ"| fin(["ปิดงานไม่สำเร็จ — จบ"])
  cl -->|"ถูกต้อง"| fin2(["หลักฐานผ่านอัตโนมัติ<br/>เมื่อรับเข้าคลัง / ค่าตอบแทนอนุมัติ"])

  classDef wait fill:#fff4e5,stroke:#f59e0b,color:#7c2d12
  class w1 wait
```

⏳ ลิงก์: [กลุ่ม 3 ทีมติดตาม](#3-ทีมติดตาม-ผู้จัดการ--หัวหน้า--พนักงานภาคสนาม) · งานคลังของธุรการดู [กลุ่ม 4](#4-คลังส่งมอบ)

> ธุรการยังช่วยงานอื่นได้: 📍 การเงิน → 50 ทวิ ลูกค้า (ติดตามหนังสือรับรองจากลูกค้า) · 📍 การตั้งค่า → ผู้ใช้งาน / Model Phone / ปฏิทินวันหยุด · 📍 การตั้งค่า → บริษัทไฟแนนซ์ → ปุ่ม "เปิด portal ของลูกค้า" (ดูอย่างเดียว)

## 3. ทีมติดตาม: ผู้จัดการ · หัวหน้า · พนักงานภาคสนาม

### 3.1 ผู้จัดการ / หัวหน้าทีม

📍 **จัดการเคส → มอบหมายงาน** · ผู้จัดการ: **การเงิน → ค่าตอบแทน** (อนุมัติขั้น 1) · **คลังสินค้า** (ดูทรัพย์ของทีม) · **รายงาน** (ปฏิบัติการ เฉพาะทีมตัวเอง)

```mermaid
flowchart TD
  %% กลุ่ม 3.1 — ผู้จัดการ/หัวหน้าทีม (lib/assignments/*)
  q(["⏳ เคสรับแล้วเข้าคิวทีม<br/>(จากกลุ่ม 2)"]) --> pk["เลือกพนักงานในทีม<br/>ดูภาระงาน/อัตราสำเร็จ"]
  pk --> pol{"หัวหน้า: ค่าตั้งเปิดให้มอบหมาย?"}
  pol -->|"ปิด (ปุ่มถูกซ่อน)"| mgr["ให้ผู้จัดการมอบหมาย"]
  pol -->|"เปิด / เป็นผู้จัดการ"| as["กด มอบหมาย → รอรับงาน"]
  mgr --> as
  as --> wa["⏳ รอพนักงานรับงาน (กลุ่ม 3.2)"]
  wa --> mon{"ติดตามความคืบหน้า"}
  mon -->|"ต้องเปลี่ยนคน"| re["กด เปลี่ยนผู้รับผิดชอบ + เหตุผล"]
  re --> st{"พนักงานเดิมรับงานแล้ว?"}
  st -->|"ยังไม่รับ"| as
  st -->|"รับแล้ว"| cons["⏳ รอพนักงานเดิมยินยอม<br/>หมดเวลา = ระบบโอนให้เอง"]
  cons --> as
  mon -->|"พนักงานปิดงาน"| exp["📍 การเงิน → ค่าตอบแทน<br/>คิวรออนุมัติขั้น 1 (ผู้จัดการ)"]
  exp --> d{"ตรวจรายการเบิก"}
  d -->|"ถูกต้อง"| apv["อนุมัติ → รอการเงินอนุมัติ"]
  d -->|"ต้องแก้"| back["ตีกลับ + เหตุผล → ถูกตีกลับ — รอแก้ไข"]
  d -->|"ไม่ควรจ่าย"| rj["ปฏิเสธถาวร + เหตุผล"]
  apv --> wf["⏳ รอการเงิน (กลุ่ม 5)"]
  back --> wa

  classDef wait fill:#fff4e5,stroke:#f59e0b,color:#7c2d12
  class q,wa,cons,wf wait
```

### 3.2 พนักงานติดตามทรัพย์ (มือถือ)

📍 **จัดการเคส → ติดตามภาคสนาม** — แท็บ หน้าแรก · รอรับงาน · รับงานแล้ว · กำลังติดตาม · จบงาน · เบิกค่าใช้จ่าย · เงินทดรองจ่าย · สรุปรายได้

```mermaid
flowchart TD
  %% กลุ่ม 3.2 — พนักงานภาคสนาม (lib/field/field-status.ts · field-nav.ts)
  n(["แจ้งเตือน: มีงานใหม่"]) --> t1["แท็บ รอรับงาน → กด รับงาน"]
  t1 --> t2["แท็บ รับงานแล้ว → กด จัดวันที่"]
  t2 --> adv{"ต้องใช้เงินทดรอง?"}
  adv -->|"ใช่"| ar["แท็บ เงินทดรองจ่าย → ขอเบิก"]
  ar --> wa["⏳ รอการเงินอนุมัติ + จ่ายในรอบจ่าย<br/>(กลุ่ม 5)"]
  adv -->|"ไม่"| t3
  wa --> t3["แท็บ กำลังติดตาม<br/>ตั้งจุดเริ่มเดินทาง · เรียงลำดับงานของวัน"]
  t3 --> ci["เช็คอิน: ที่อยู่ / ผู้ติดต่อ / ที่ทำงาน / ที่อยู่ทรัพย์<br/>ถ่ายรูป · บันทึกร่างปิดงาน"]
  ci --> res{"ได้เครื่องคืน?"}
  res -->|"ได้"| cs["กด ยืนยันปิดงาน (สำเร็จ)<br/>ส่งเครื่องเข้าคลัง"]
  res -->|"ไม่ได้"| cf["กด ยืนยันปิดงาน (ไม่สำเร็จ)<br/>เลือกเหตุผล"]
  res -->|"ยังไม่จบ"| t3
  cs --> wh["⏳ รอคลังรับเข้า (กลุ่ม 4)"]
  cs --> ev
  cf --> ev{"หลักฐานถูกตีกลับ?"}

  fx --> ev
  ev -->|"ไม่"| clm["แท็บ เบิกค่าใช้จ่าย<br/>ค่าที่พัก / ค่าใช้จ่ายมีใบเสร็จ<br/>(ค่าน้ำมัน/เบี้ยเลี้ยงรายวัน ระบบคิดให้)"]

  wap --> rv{"รายการถูกตีกลับ?"}
  rv -->|"ใช่"| fix2["แก้ไขแล้วส่งใหม่"]
  fix2 --> wap
  rv -->|"ไม่"| inc["แท็บ สรุปรายได้<br/>ดูยอดที่จะได้รับในรอบจ่าย"]
  rq{"มีคำขอโอนงานของฉัน?"} -->|"ยินยอม / ปฏิเสธ"| t3

  classDef wait fill:#fff4e5,stroke:#f59e0b,color:#7c2d12

```

## 4. คลัง/ส่งมอบ

**ใคร:** ธุรการ (ทำงานคลังทั้งสาย) · การเงิน/บัญชี/บริหาร/ผู้จัดการทีมดูอย่างเดียว
📍 **คลังสินค้า** · **เมื่อไร:** ทุกวันที่มีเครื่องเข้า · ทุกรอบนัดส่งมอบ

```mermaid
flowchart TD
  %% กลุ่ม 4 — คลัง (lib/warehouse/*) · IMEI ผ่าน parseImei จุดเดียว
  n(["แจ้งเตือน: มีทรัพย์ รอรับเข้าคลัง"]) --> sc["สแกน/กรอก IMEI ของเครื่องที่ได้รับ"]

  v -->|"ไม่ตรง / อักขระแปลก / ไม่ครบ"| rj["กด ตีกลับ + เหตุผล → ตีกลับ"]
  rj --> fq["⏳ ติดต่อทีมติดตาม/ตรวจข้อมูลเคส<br/>(กลุ่ม 3)"]
  fq --> sc
  v -->|"ตรง"| cd["บันทึกสภาพ: ปกติ / เสียหาย / สูญหายบางส่วน<br/>ถ่ายรูป → กด รับเข้าคลัง"]

  ic --> due{"ถึงรอบส่งมอบของบริษัท?"}

  ty -->|"ไฟแนนซ์มารับ"| a1["พิมพ์เอกสารส่งมอบ 1 ชุด<br/>→ รอแนบใบเซ็นรับ"]
```
