# ค่าตั้งเริ่มต้นตามมาตรฐานการเงิน/ภาษีไทย (preset `thai-standard`)

> ไฟล์ค่าตั้ง: `scripts/settings-preset/presets/thai-standard.json` · ใช้ได้ทั้งเครื่อง dev และ staging/production
> ทุกค่าเขียนผ่านหน้าที่เดียวกับหน้าตั้งค่า (ตรวจความถูกต้อง + บันทึกประวัติการแก้ไขพร้อมเหตุผล) — ไม่เขียนฐานข้อมูลตรง

## ใช้งาน

| ต้องการ | คำสั่ง |
|---|---|
| ดูก่อนว่าจะตั้งอะไร (ไม่เขียนจริง) | `pnpm settings:preset --apply --dry-run` |
| ตั้งค่ามาตรฐาน | `pnpm settings:preset --apply` |
| ตั้งเฉพาะบางหมวด | `pnpm settings:preset --apply --only=vatRates,taxProfiles` |
| เก็บค่าตั้งปัจจุบันไว้ใช้ภายหลัง | `pnpm settings:preset --export=manual/presets/<ชื่อ>.json` |
| ใช้ค่าตั้งที่เก็บไว้ | `pnpm settings:preset --apply --preset=manual/presets/<ชื่อ>.json` |
| บน staging | `uat/bin/staging-prep.sh preset [--dry-run]` · `uat/bin/staging-prep.sh preset-export <ไฟล์>` |

- สคริปต์ไม่โหลด `.env*` เอง — ส่ง `DATABASE_URL` จาก shell · ฐานนอกเครื่องต้องสั่ง `--target=staging` · ฐาน production ถูกปฏิเสธ (ขึ้น production ให้ตั้งผ่านหน้าจอ หรือเพิ่มเป้าหมายใหม่พร้อมมติ)
- ผู้ตั้ง = Superadmin (`admin` บนเครื่อง · `superadmin` บน staging · เปลี่ยนด้วย `SETTINGS_PRESET_SUPERADMIN`)
- รันซ้ำได้: แถวที่มีอยู่แล้ว (ชื่อ/วันที่มีผลตรงกัน) ข้าม · ค่าตั้งเดี่ยว (นโยบายการเงิน · ระยะเก็บ · SLA/มอบหมาย) ตั้งทับ
- หมวดที่มี `needsAccountant: true` บันทึกเหตุผลพร้อมป้าย "[รอนักบัญชียืนยัน]" — ให้นักบัญชีตรวจที่หน้า "ค่าตั้งที่รอนักบัญชียืนยัน" แล้วกดยืนยัน

## สิ่งที่ preset **ไม่** ตั้ง (ข้อมูลเฉพาะธุรกิจ — ตั้งผ่านหน้าจอตามคู่มือผู้ดูแลระบบ)
ข้อมูลองค์กร/โลโก้/ลายเซ็น · บัญชีธนาคารบริษัท · รูปแบบไฟล์ธนาคาร · แผนค่าตอบแทน · เทมเพลตค่าบริการ · ทีม · บริษัทไฟแนนซ์และรอบวางบิล · ผู้ใช้และข้อมูลรับเงิน · ฐานรุ่นมือถือ

## ปรับค่าให้เหมาะกับบริษัท
1. แก้ผ่านหน้าตั้งค่าตามปกติ (ทุกการแก้มีประวัติ)
2. เมื่อได้ชุดที่ใช้จริงแล้ว `--export` เก็บเป็น preset ของบริษัท (เช่น `manual/presets/company-2569.json`) ไว้ใช้ตั้งระบบใหม่/ฐานใหม่
3. ค่าที่เปลี่ยนตามกฎหมาย (VAT · วันหยุด) ให้เพิ่มแถวใหม่ตามวันที่มีผล — ระบบเก็บค่าตามวันที่ (snapshot) ไม่คำนวณย้อนหลัง
