🖥 บริการ (เปิดค้างไว้ระหว่างทำงาน)

🐘 ฐานข้อมูล Postgres

Docker Postgres
ฐานข้อมูลหลัก ต้องเปิดก่อน API เสมอ — แก้อาการ "DATABASE_URL required" / "connection refused" ตอนเปิด API
Drizzle Studio
เปิดหน้าเว็บดู/แก้ข้อมูลในตารางโดยตรง — ใช้ตรวจว่าข้อมูลเข้าถูกไหม (เปิด Postgres ก่อน)

🗄 จัดการข้อมูล

db:migrate
อัปเดตโครงสร้างตารางให้ล่าสุด — รัน หลังเปิด Postgres ครั้งแรก หรือหลัง pull โค้ดที่มี migration ใหม่
seed demo
ใส่ข้อมูลตัวอย่าง [DEMO] (พาร์ทเนอร์/ทะเบียน/ตั้งค่า) ไว้ทดลองใช้งานระบบ
clear demo
ลบข้อมูล [DEMO] ทั้งหมด — ใช้ ก่อนกรอกข้อมูลจริง ของธุรกิจ

🔍 ตรวจสุขภาพโค้ด (ก่อน commit)

typecheck
ตรวจชนิดข้อมูล TypeScript ทั้งโปรเจค — เร็ว ใช้เช็คว่าโค้ดไม่พังก่อนรันจริง
test
รันเทสต์ทั้งหมด (~90 วินาที) — ยืนยันว่าไม่มีอะไรถอยหลังหลังแก้โค้ด
build หน้าบ้าน
ลอง build เว็บสาธารณะจริง (ตั้ง ulimit + โหลด env ให้เอง) — ต้องเปิด API ไว้ด้วย เพราะ build ดึง config จาก API
